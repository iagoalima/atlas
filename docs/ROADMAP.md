# Planejamento

Este documento registra áreas que podem orientar futuras melhorias. Os itens não representam promessas de entrega nem funcionalidades já implementadas.

## Prioridades de qualidade
- [ ] Executar testes funcionais dos fluxos principais em um servidor de teste.
- [ ] Adicionar testes automatizados para regras de negócio críticas.
- [ ] Validar a recuperação após falhas de banco de dados e da API do Discord.
- [ ] Revisar logs para minimizar exposição de dados pessoais.
- [ ] Documentar procedimentos de backup e restauração.
- [ ] Confirmar o processo de versionamento e publicação de releases.

## Evolução futura
Novas funcionalidades devem ser priorizadas conforme necessidades reais dos operadores e após avaliação de segurança, manutenção e impacto nos fluxos existentes.
